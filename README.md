# 🚀 AtlasAI

### Your Intelligent AI-Powered Development Workspace

AtlasAI is an AI-powered development platform designed to make building, experimenting with, and working with code easier. It combines a modern web interface with developer-focused tools to create a streamlined coding experience.

🌐 **Live Demo:** https://atlas-ai-amber.vercel.app/

---

## ✨ Features

- 🤖 **AI-Powered Experience** — An intelligent interface designed to enhance developer productivity.
- 💻 **Code Editor** — Integrated code editing experience powered by Monaco Editor.
- ⚡ **Live Code Preview** — Interactive code execution and preview capabilities using Sandpack.
- 🎨 **Modern UI** — Clean, responsive interface built with React.
- 🔐 **Authentication** — Firebase integration for authentication services.
- 💳 **Payment Integration** — Razorpay integration for payment-related functionality.
- 📝 **Code Highlighting** — Syntax-highlighted code rendering for better readability.
- 📱 **Responsive Design** — Designed to work across different screen sizes.

## 🚀 Getting Started

Follow these steps to run AtlasAI locally.

### Prerequisites

Make sure you have installed:

- Node.js (LTS recommended)
- npm
- Git

### 1. Clone the Repository

```bash
git clone https://github.com/Abhisek-desk/AtlasAI.git
```

### 2. Navigate to the Project

```bash
cd AtlasAI
```

### 3. Set Up the Frontend

```bash
cd frontend
```

Install dependencies:

```bash
npm install
```

### 4. Start the Development Server

```bash
npm run dev
```

The frontend will be available at:

```text
http://localhost:5173
```
